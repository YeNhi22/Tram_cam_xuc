Sao lưu nhật ký

Tải file về máy để giữ an toàn. Xoá lịch sử trình duyệt sẽ mất dữ liệu, nên thỉnh thoảng bấm "Tải về" một phát nhé. Muốn khôi phục thì bấm "Nhập lại" rồi chọn file đã lưu.
